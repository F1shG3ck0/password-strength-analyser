# Password Security Analyser

## Project Status

🚧 Currently in Development

This project is currently being developed as a personal cybersecurity and web development project. The aim is to create a web application that analyses password strength and educates users on password security best practices.

## Overview

Weak passwords remain one of the most common security vulnerabilities. This application is designed to assess password strength, provide actionable feedback, and communicate the reasoning behind common password security requirements.

The project is being developed using Python and Flask to gain practical experience in:

- Cybersecurity fundamentals
- Secure coding practices
- Web application development
- User input validation
- Version control with Git and GitHub
